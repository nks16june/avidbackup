# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x | Yes |

## Reporting a vulnerability

Please use **GitHub Security Advisories** on this repository when available, or email **nishant@avidwebsolutions.in** with:

- AvidBackup version
- Description and impact
- Steps to reproduce (no production passwords)

We aim to acknowledge within a few business days.
