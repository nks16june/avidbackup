PHP helper

AvidBackup uploads one small PHP file to the site over the site's FTP/SFTP login, with a random file name and a secret token (only its hash is kept on the server). It sends a read-only dump of this one database over HTTPS. It runs no shell commands. The file contains the database login, like wp-config.php does, so remove it when you no longer need it.
