# Benefits

AvidBackup is a **free, local-first** backup utility for websites and databases. It pulls files over FTP/FTPS/SFTP and dumps MySQL, PostgreSQL, or SQLite to your own disk — no cloud agent, no telemetry.

## Highlights

1. **Own your backups** — data stays on your machine  
2. **Multi-site UI** — Softaculous-*style* account list (no affiliation)  
3. **Files forever** — remote deletes do not wipe local copies  
4. **Honest initial full** — zero-failure gate before incremental  
5. **Multi-database** — several DB types per site  
6. **Configurable retention** — DB dumps (default 15 days); files kept forever by default  
7. **Cross-platform** — Windows installer, pipx, Docker, or source; `AVIDBACKUP_HOME` anywhere
